Place the licensed GT Walsheim web font files here (from GT brand assets):

  GTWalsheim-Regular.woff2   (weight 400)
  GTWalsheim-Medium.woff2    (weight 500)
  GTWalsheim-Bold.woff2      (weight 700)

If the files are missing the dashboard falls back to a locally installed
"GT Walsheim" / "GT Walsheim Pro", then to system fonts.
Do not commit the font files to a public repository (licensed asset).
